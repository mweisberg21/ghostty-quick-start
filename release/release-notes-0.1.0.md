First public release of Ghostty Quick Start, an unofficial Ghostty fork for macOS.

- Pin project folders in the sidebar.
- Open a shell, Claude, Codex, Cursor CLI, or a custom command in a selected folder.
- Return to running tabs from the sidebar.
- See native app icons for supported foreground programs.
- Check for signed updates from this repository.

Requires macOS 13 or later. Includes Apple silicon and Intel binaries. The CLI tools are installed separately. Pins and folder settings are local to each Mac.

Based on Ghostty source commit 44f2a44df7e8c4a0c6df3f7d872ef3d7ead88e51 (1.3.2-dev). The original Ghostty MIT license is retained.
