The sidebar now provides the main tab controls.

- Drag its right edge to resize it. The app saves the width.
- Collapse the sidebar to icons, then expand it to the saved width.
- The top tab bar is hidden by default. Use View → Show Top Tab Bar to restore it.
- Right-click a sidebar tab to close, rename, change its color, or move it to another window.
- Use the + button to create a tab. Hover over a tab to show its close button.
- Tab colors match in the sidebar and top bar. Existing keyboard shortcuts and close warnings still work.

The sidebar lists each window's tabs in their native order. Folder pins can still return to sessions in other windows.

Requires macOS 13 or later. Includes Apple silicon and Intel binaries. The CLI tools are installed separately.
