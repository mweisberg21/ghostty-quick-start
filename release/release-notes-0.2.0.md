Ghostty Quick Start now has a native Settings window. Open Settings from the Ghostty menu or press ⌘,.

- Show the top tab bar, collapse the project sidebar, and adjust its width.
- Choose a theme or font, change text size and opacity, and adjust terminal padding.
- Manage pinned folders and their Shell, Claude, Codex, Cursor CLI, or custom launch actions.
- Control automatic update checks and downloads. See the last check time and update status.
- Open the config file and review configuration errors in Advanced.

The Settings sidebar button stays on the left when the sidebar is open or closed. Settings opens in its own window and keeps terminal tabs in place.

Appearance choices are saved for this fork only. The normal Ghostty config file stays intact. Use Config File restores the file's appearance values.

Top tabs are visible by default. Saved visibility choices from earlier versions are kept.

Requires macOS 13 or later. Includes Apple silicon and Intel binaries. The CLI tools are installed separately.
